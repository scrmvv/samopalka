# Самопалка — веб-версия настольной игры

## Требования

- Node.js 20.19 или новее (рекомендуется актуальная LTS-версия).
- Windows / macOS / Linux и современный браузер.
- Для игры с друзьями: доступ к компьютеру с сервером по локальной сети, VPN или настроенному внешнему адресу.

## Первый запуск

1. Скачайте репозиторий: **Code → Download ZIP**, распакуйте архив в удобную папку. Или используйте `git clone`.
2. Откройте терминал **в папке с `package.json`**.
3. Установите зависимости:

   ```powershell
   npm install
   ```

   В Windows, если PowerShell блокирует `npm.ps1`, используйте `npm.cmd install`.
4. Соберите проект:

   ```powershell
   npm run build
   ```

   В Windows можно `npm.cmd run build`.
5. Запустите сервер:

   ```powershell
   npm start
   ```

   В Windows можно `npm.cmd start`.
6. Откройте в браузере **http://localhost:3000**. Создайте комнату и передайте друзьям код комнаты.

**Важно:** не закрывайте терминал с сервером во время игры. После перезапуска сервера активные комнаты не сохраняются.

## Как обновить уже установленную версию

**Если скачивали через Git:**

1. Остановите сервер (`Ctrl+C`).
2. В папке проекта выполните `git pull` (сначала сохраните свои локальные изменения, если они есть).
3. Выполните `npm install` → `npm run build` → `npm start`.
4. Перезагрузите страницу браузера с очисткой кеша (`Ctrl+F5`) и создайте новую комнату.

**Если скачивали ZIP:**

1. Остановите сервер (`Ctrl+C`).
2. Сохраните копию прежней папки проекта.
3. Скачайте свежий ZIP с GitHub и **распакуйте в новую папку**, не смешивая старые и новые файлы.
4. В новой папке с `package.json` выполните `npm install`, затем `npm run build` и `npm start`.
5. Откройте страницу заново и создайте новую комнату.

## Игра по сети

На компьютере, где запущен сервер, используется порт **3000**. Друзья должны открыть в браузере `http://IP_ХОСТА:3000` (IP компьютера в общей локальной сети или VPN). Radmin VPN — лишь один из вариантов; другие VPN тоже подходят при наличии прямой сетевой связности. Участникам не нужно устанавливать Node.js: только браузер. Если подключение не работает, проверьте доступность хоста, правила брандмауэра для TCP 3000 и ограничения VPN. Не открывайте сервер в публичный интернет без дополнительной защиты.

## Время хода

В текущей демонстрационной сборке выставлено **60 секунд** для обычного и сокращённого хода. Для проверки согласованного режима **15/5 секунд** в PowerShell перед запуском:

```powershell
$env:TURN_SECONDS='15'
$env:SHORT_TURN_SECONDS='5'
npm.cmd start
```

Новые значения применяются к **новым партиям**. Для возврата к 60/60 откройте новый терминал без этих переменных (или установите обе равными 60).

## Что входит в этап 2

- Сетевая комната и выбор персонажей (этап 1).
- Круговая арена: игроки снаружи, монстры внутри, общий босс в центре.
- Бросок кубиков, выбор результата, очередь ходов, таймер, журнал.
- Панель артефактов и эффектов в виде подготовленного интерфейса.
- Чат пока является заглушкой.

**Ограничение:** монстры и босс пока представлены визуально; урон, полноценные артефакты и бой относятся к этапу 3.

## Разработчику

Монорепозиторий npm workspaces: `apps/client` (React/Vite), `apps/server` (Node.js/Socket.IO), `packages/shared` (общие типы). Для разработки доступны `npm run dev:server` и `npm run dev:client` в отдельных терминалах. Проверка: `npm test`.
