# Как добавить этот релиз в существующий GitHub-репозиторий

Релиз: 28.10.2026, этап 3.2 + объединённый хотфикс.

## Вариант 1 — полный чистый архив (рекомендуется)

1. Сохраните копию локального репозитория, убедитесь, что нет несохранённых изменений: `git status`.
2. Распакуйте `samopalka_stage3_2_github_full.zip` прямо **в корень существующего репозитория**, рядом с `.git` и `package.json`.
3. Не удаляйте папку `.git`: она нужна для сохранения истории коммитов.
4. В терминале выполните:

```bash
git status
git diff --stat
npm install
npm run build
npm test
git add .
git commit -m "fix: consolidate stage 3.2 feedback and responsive UI"
git push
```

Команды `npm` запускайте при доступных зависимостях и интернете. Если сборка или тесты не прошли — не публикуйте как проверенный релиз, сначала устраните ошибки. В Windows PowerShell при блокировке `npm` используйте `npm.cmd`.

**Важно:** архив представляет исходный код без `.git`, `node_modules`, `dist` и временных файлов. Он не меняет историю репозитория. Не публикуйте свои секреты, `.env`, содержимое тестовых комнат.

## Вариант 2 — архив только с отличиями от предыдущего GitHub-этапа 2

`samopalka_stage3_2_github_update.zip` содержит только изменённые или новые файлы относительно ранее подготовленного `samopalka_stage2_commit_ready.zip`. Распакуйте его в корень репозитория с заменой соответствующих исходников, затем выполните команды выше. В этом сравнении файлов для удаления нет.

Если ваш локальный репозиторий уже содержит промежуточные фиксы 3.1/3.2, все равно проверьте `git diff` перед коммитом. Не копируйте архив в подпапку: структура `apps/`, `packages/`, `docs/` должна остаться на верхнем уровне.

## Проверка перед передачей заказчику

- `npm run build` завершается без ошибок TypeScript/Vite.
- `npm test` выполняется без падений.
- В игре работают выбор одинаковых героев, выход по таймеру, отмена грани до применения, новые цели после гибели героя и босса, переход на новый этаж без старых монстров.
- Проверено чтение статов и вывод нижнего героя на большом мониторе, а также поле на небольшом ноутбуке.
- Окно подтверждения выхода видно поверх экрана победы, затемняется весь экран.
