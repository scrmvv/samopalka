# Самопалка — обновление 3.3.4 (закрытый тест)

## Исправления по замечаниям заказчика

1. Убраны декоративные круги. Монстры занимают индивидуальные grid-слоты возле текущего владельца. Переманенные и переданные после смерти монстры перераспределяются автоматически. На поле сохранены пиксельные персонажи, босс в центре и фон подземелья.
2. По нажатию на монстра или босса открывается карточка с характеристиками и полным описанием из каталога. При выборе цели основное нажатие атакует; рядом с фигуркой есть отдельная кнопка информации.
3. Действия монстров и босса исполняются последовательно на сервере. Между действиями существ и передачей хода следующему герою — пауза 2 сек. Таймеры самого хода остаются прежними.
4. Рост и Гниение относятся к КОНКРЕТНОЙ грани и увеличивают/уменьшают её на 1 ПОСЛЕ использования. Гниение не снижает ниже 0. Гниение монстров изменяет их собственную напечатанную грань, а не грани героев.
5. Сон снимается словом «Удар», даже если удар полностью поглощён щитом или уворотом. Яд и «Боль» не будят.
6. Паралич добавляет «Боль» к используемой грани на один ход: урон по текущему значению грани, щит его поглощает. Паралич снимается по завершении собственного хода.
7. Усилена подсветка активного героя.
8. Для отладки добавлены варианты граней «Удар + Рост» и «Удар + Гниение»; в каталог противников открыты полные описания.

## Важно для тестировщика

- Это **закрытая тестовая сборка**, панель «ТЕСТ» включена по умолчанию, доступна только хосту.
- Для отключения на публичном сервере задайте `DEBUG_TOOLS=0`.
- Стартовые кубики героев не получили новых Рост/Гниение сами по себе: в 3.3.4 эти комбинации удобно проверять через панель; получение их через артефакты — задача 3.4.
- Панель позволяет назначать тестовые варианты граней до броска активного героя.
- «Очищение» как получаемое действие пока не добавлено (потребуется система артефактов 3.4).
- Браузерные и сетевые проверки с друзьями всё ещё необходимы.

## Установка поверх 3.3.3

Распаковать patch архив в корень проекта с заменой файлов; затем:

```cmd
npm.cmd install
npm.cmd run build
npm.cmd test
npm.cmd start
```

Для Windows CMD отладку можно принудительно отключить `set DEBUG_TOOLS=0` перед запуском.
