# Самопалка — 3.4.3-test (19.11.2026)

База: **3.4.2-test**. Независимо применять поверх более старой версии нельзя.

## 1. Монстр «Проклятый» / «Удар, Гниение, 5»

- После каждого использования собственной грани её постоянное значение снижается на 1: `5 → 4 → 3 → 2 → 1 → 0`.
- Значение никогда не становится отрицательным. Урон следующего удара рассчитывается от уже сниженной силы.
- Каталог противников не меняется: конкретный экземпляр монстра хранит собственное изменение грани.
- Сервер публикует *текущую* грань в данных Бестиария; сила видна на фишке монстра и в его карточке, а не всегда как исходные «5».
- Подмена монстра через «ТЕСТ» сбрасывает историю изменения его грани.
- «Слабость» отдельно уменьшает эффективность текущей атаки; в журнале роста/гниения показывается изменение **напечатанной грани**, без временной слабости.

## 2. ТЕСТ → ВЫДАТЬ АРТЕФАКТ

Поля: герой → фильтры уровня и класса → конкретный артефакт → при необходимости грань 1–6 → «Выдать артефакт».

- Доступен **реализованный каталог** `apps/server/src/artifacts.ts`: 97 артефактов. Это не все 350 предметов из новой версии таблицы; предметы без реализованного эффекта пока не добавлены.
- Можно выдать артефакт любого уровня любому герою, повторно выдать тот же артефакт, протестировать его пассивный/расходуемый эффект.
- Предметы с заменой/удвоением выбирают грань. Другие не занимают грань.
- Вызов использует **ту же функцию применения**, что и обычная выдача награды, без изменения очереди, доступных карт, таймера или этажа.
- Разрешено во время боя и привала, но не в завершённой/приостановленной игре.
- Обрабатывает только сервер после проверки `DEBUG_TOOLS=1` и действующего сокета хоста комнаты.
- В публично доступном тестовом стенде любой посетитель, создавший свою комнату, имеет права хоста **только своей комнаты**. Не используйте DEBUG_TOOLS=1 на боевом публичном сервере.

## Ручные проверки

1. В начале боя через «ТЕСТ → ПРОТИВНИК» заменить обычного монстра на «Проклятый». Дождаться его двух атак; в Бестиарии/на фишке должно быть сначала «5», потом «4», «3». Урон без щита/слабости соответственно 5 и 4.
2. Выдать Воину предмет «Грань · Удар, Гниение, 3» и заменить **вторую**, а не первую сторону. Остальные грани не должны поменяться.
3. Выдать Лекарю предмет на `+max HP`; он не должен запросить грань. Полученный предмет появится в инвентаре Лекаря, а не у хоста.
4. Выдать артефакт уровня выше текущего этажа. Предмет должен примениться, но таблица предложений наград не должна измениться.
5. Проверить, что у второго игрока нет кнопки «ТЕСТ» и он не может выдавать артефакты через сокет.
