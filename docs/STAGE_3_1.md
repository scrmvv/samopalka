# Этап 3.1 — базовые боевые слова

Это промежуточная рабочая версия боевой системы, предназначенная для проверки в браузере с несколькими игроками.

## Что сделано

- Сервер хранит и синхронизирует здоровье, максимальное здоровье, щит и ману.
- После броска двух кубиков выбирается одна выпавшая грань.
- **Удар:** выбрать подсвеченную цель; щит цели поглощает урон прежде здоровья.
- **Щит:** выбрать живого героя (включая себя); к его текущему щиту добавится значение грани.
- **Лечение:** выбрать живого героя; здоровье восстанавливается, но не превышает максимум.
- **Мана:** зачисляется владельцу грани автоматически; избыток сверх тестового лимита сбрасывается в конце хода.
- «Пусто» заканчивает ход без эффекта.
- Все действия проверяет сервер: чужой ход, просроченный таймер и недоступная цель отклоняются.
- В журнале фиксируются действия, состояние героев/противников отображается на круговом поле.
- При гибели героя его ходы пропускаются. Выбывший герой остаётся на поле как отметка о результате боя.

## Как проверить вдвоём

1. Запустить сервер и открыть два браузера (два отдельных профиля / инкогнито) либо подключиться через VPN.
2. Создать комнату на 2 игроков, выбрать разных героев, подтвердить готовность и начать партию.
3. Дождаться на активном герое грани **Удар**: выбрать результат, затем щёлкнуть по доступной подсвеченной цели. Здоровье изменится у обоих игроков одновременно.
4. Для **Щита** выбрать героя на поле. Его значение щита появится рядом со здоровьем.
5. Другим ударом в того же героя проверить поглощение урона щитом.
6. Для **Лечения** выбрать раненого героя; здоровье не превысит максимум.
7. Для **Маны** выбрать соответствующую грань — ресурс добавляется владельцу без выбора цели.
8. Попробовать выбирать чужие фигуры вне своего хода и атаковать босса до убийства своего монстра: сервер не должен принимать такие действия.
9. Перезагрузить одну вкладку: после переподключения состояния здоровья, щитов и маны должны совпасть у всех.

### Тестовые упрощения (НЕ утверждённый баланс)

- **Монстр: 10 HP; босс: 30 HP; максимум маны героя: 6.** Эти значения выставлены только для проверки технической работы. PDF не задаёт общие фиксированные значения для всех противников и максимальный запас маны.
- Для первого теста удар доступен по личному монстру и другим живым героям. Босс становится доступен, когда личный монстр побеждён. Это предварительная схема выбора целей: ограничения дальности, соседства и модификаторы ещё будут уточняться и реализовываться.
- Щит и лечение можно применять к живым героям без проверки расстояния; на следующих этапах будет полноценная проверка дальности и модификаторов.
- Противники сейчас **не атакуют автоматически**. Щит удобно проверять ударами второго игрока.
- Временных эффектов, дополнительных слов, действия ролей и артефактов, переходов между этажами здесь нет.
- Грани с дополнительными словами (например, «Самооборот», «Насмешка») выводятся и журналируются, но **пока не дают игрового эффекта**. Разбор комплексных граней относится к 3.3.
- При гибели босса тестовый бой останавливается без автоматического перехода на следующий этаж.

## Установка

Скопировать файлы патча в корень **исходников второго этапа** с заменой, не удаляя остальные файлы. Команды в корне проекта:

```powershell
npm.cmd install
npm.cmd run build
npm.cmd start
```

После обновления обязательно перезапустить сервер и создать **новую** комнату: старое состояние боёв хранится только в памяти. Проверьте браузер через `Ctrl + F5`.

Для тестовых таймеров остаётся 60/60. Для 15/5 перед `npm.cmd start` выставить:

```powershell
$env:TURN_SECONDS='15'
$env:SHORT_TURN_SECONDS='5'
```
