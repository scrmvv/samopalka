# Самопалка 3.4-test — быстрый тест для заказчика

Это **ранняя тестовая версия подэтапа 3.4**, а не финальная реализация всех артефактов.

## Что добавлено

1. После победы над всеми монстрами и боссом на 1–5 этажах начинается **привал**. Герои получают `2 + d6` HP (не больше максимума).
2. Игроки по очереди выбирают **один из четырёх** предложенных артефактов. Остальные передаются следующему; недостающие до четырёх добираются из колоды этого тира.
3. От артефакта разрешено отказаться: `+2` к максимальному HP **без автоматического лечения** или `+1` к значению одной стороны кубика.
4. Для карты «Заменяет сторону ...» игрок выбирает грань перед получением награды. Выбор необратим и сохраняется на следующих этажах.
5. Поддержаны сервером эффекты базовых слов, Рост, Гниение, Яд, Слабость, Боль, Дальнобойность, Разброс, Самощит, Самолечение, Самоуворот, Очищение и сочетания со Щитом/Маной/Лечением в рамках доступных карт.
6. Есть инвентарь выбранных реликвий и первая одноразовая лечебная реликвия (5 HP), доступная только владельцу в его ход.
7. Исправлено положение иконок `i` у всех монстров и босса.

## Что пока **не** включено в тест

- Полный каталог (~350) предметов из исходного XLSX: в раздачу попадают **только 97 карт с подключёнными обработчиками**. Описания сохранены из таблицы; форматовые названия упрощены.
- Ограничения артефактов по классам: типы «Воин / Защ / Леч / Маг / Унив» показываются, но пока **не запрещают** взять карточку другому классу. Это сознательная особенность закрытой тестовой версии, чтобы все игроки могли проверить механику и не зависеть от ещё не согласованных ролей.
- Большинство заклинаний за ману, пассивные «каждый ход», альтернативные типы победы/задания ролей.
- Сохранение комнат после остановки Node-сервера.

## Быстрая ручная проверка

1. Запустите `npm.cmd run build`, затем `npm.cmd start` (для тестовой панели отдельный флаг не нужен).
2. Создайте комнату на 2–3 участников и зачистите первый этаж через панель «ТЕСТ» или честным боем.
3. Убедитесь, что открыты **4 артефакта первого тира**, герои восстановили здоровье, а выбор доступен **только текущему игроку**.
4. Выберите замену на **грань 6**. У следующего участника должно остаться **4 предложения**, но выбранной вами карточки в них больше нет.
5. Проверьте альтернативы `+2 к максимальному HP` и `+1 к грани 6`, затем переход на второй этаж. Изменения должны сохраниться.
6. Найдите расходуемый лечебный артефакт в инвентаре, примените его во время собственного хода. Повторное использование не допускается.
7. Проверьте карточку монстра `i` у каждого врага и босса, включая перенесённых Насмешкой монстров.
8. Проверьте, что кнопка перехода к следующему этажу становится доступной хосту **только после** выбора награды всеми игроками.

## Автоматическое тестирование

Для GitHub-версии:

```cmd
npm.cmd run build
npm.cmd test
npm.cmd run simulate -- --games 100 --players 4 --seed 42 --strategy mixed --out reports/3.4-mixed.json
npm.cmd run simulate -- --games 40 --players 4 --mode campaign-smoke --out reports/3.4-campaign.json
```

`campaign-smoke` сознательно облегчает бои и не предназначен для оценки баланса.

## Правила безопасности

Панель `ТЕСТ` разрешена только хосту и включена по умолчанию **для закрытой сборки**. Перед открытой публикацией явно выставьте `DEBUG_TOOLS=0` в окружении сервера.
