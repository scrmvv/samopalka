# Самопалка — 3.3.4.1, визуальный хотфикс

Исправления по тестированию версии 3.3.4 (три замечания):

1. **Бестиарий.** В окне описания врага больше не видны горизонтальная и вертикальная полосы прокрутки. Длинное описание по-прежнему доступно прокруткой колёсиком мыши, пальцем либо клавиатурой. Ширина модального окна ограничена шириной экрана; кнопка и текст не выпирают.
2. **Размеры арены.** Поле боя использует всю доступную ширину левого блока, а не только центральную квадратную область. На планшетах и телефонах высота поля увеличена, чтобы не складывать фигурки друг на друга. Декоративные круги не возвращены.
3. **Насмешка.** Переманенные противники выстраиваются перед текущим владельцем симметрично относительно линии герой → босс. Учитываются реальные размеры поля, фигуры героев, босса, остальных монстров и границы игрового поля. После смерти владельца позиции пересчитываются; мёртвые монстры не резервируют место.

Обычные боевые правила, статистика противников, таймеры и серверные действия не менялись. Тестовая панель «ТЕСТ» по-прежнему включена по умолчанию в сборке для заказчика и доступна только хосту. Для отключения используйте `DEBUG_TOOLS=0`.

## Как установить

Остановить сервер (`Ctrl+C`), распаковать патч поверх **3.3.4** с заменой файлов, затем выполнить:

```cmd
npm.cmd run build
npm.cmd test
npm.cmd start
```

После обновления страницы браузера с очисткой кэша (`Ctrl+F5`) проверить:

- открыть описание монстра и босса на компьютере и мобильном экране;
- сыграть 2–3 участниками; переманить двух монстров к Рыцарю: фигуры должны расположиться по обе стороны от линии перед ним, не закрывая Рыцаря и босса;
- убить Рыцаря и убедиться, что перемещённые монстры занимают отдельные места возле следующего владельца;
- проверить комнату из 5–6 игроков, изменение ширины окна, выбор целей и кнопки информации.

## Проверка подготовленного патча

- 102/102 геометрических теста (размещение на 2–6 игроков, 0–3 дополнительных монстра одного владельца, 5 размеров арены; отдельно симметрия и перенос после смерти).
- Исходник `boardLayout.ts` прошёл проверку TypeScript; TSX прошёл синтаксическую компиляцию TypeScript.
- В изолированном браузерном макете проверены расширенная сцена, симметричные позиции монстров и окно «Бестиарий» без видимых полос прокрутки.
- Полная npm/Vite-сборка не выполнена в текущей среде: npm-пакеты отсутствуют и реестр npm недоступен. Необходима локальная проверка перед отправкой заказчику.
