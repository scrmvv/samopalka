# Самопалка 3.3.3 — закрытый мультиплеерный тест

Эта версия предназначена для тестирования с друзьями, **не для публичного размещения**. Отладочная панель **«ТЕСТ» включена по умолчанию** и появляется у хоста после начала партии. Гостям панель не доступна.

## Запуск на Windows

1. Распаковать архив в отдельную папку.
2. Открыть CMD или PowerShell в папке с `package.json`.
3. Выполнить `npm.cmd install`, затем `npm.cmd run build`, затем `npm.cmd start`.
4. Открыть `http://localhost:3000`. Для друзей использовать IP компьютера хоста в локальной сети или VPN.

## Что тестировать

- Играть вдвоём, втроём и вчетвером; проверять корректность очереди и целей.
- Рыцарь: Насмешка, переманенные монстры, смерть героя и передача противников.
- Яд, сон, слабость, щит, уворот и иные состояния — до и после перехода на следующий этаж.
- Повторная партия: хост возвращает всех в то же лобби, герои и код комнаты сохраняются, готовность сбрасывается.
- Переподключение во время боя, смена сети, отображение на маленьком экране.

## Безопасность

**Обязательно** задавать `DEBUG_TOOLS=0` перед публичным запуском. В Windows CMD: `set DEBUG_TOOLS=0`, затем `npm.cmd start`; в PowerShell: `$env:DEBUG_TOOLS='0'`, затем `npm.cmd start`. Публичная версия с включённой панелью позволяет хостам менять параметры боя.

## Что ещё не входит

Артефакты и улучшение граней (3.4), роли (3.5), полноценный чат. Баланс ещё требует проверки людьми.
