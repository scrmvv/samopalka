# Как запустить и обновить «Самопалку»

Эта инструкция — для заказчика, который хочет самостоятельно протестировать игру с друзьями. Сборка содержит этапы 1–3.2 и последние исправления. Управление боем ещё дополняется, поэтому некоторые артефакты и специальные эффекты пока недоступны.

## 1. Первый запуск на своём компьютере

1. Установите **Node.js 20.19 или новее** с официального сайта nodejs.org. После установки откройте новый терминал.
2. На странице GitHub-репозитория нажмите **Code → Download ZIP** (либо скопируйте репозиторий через `git clone`). Распакуйте в отдельную папку.
3. Откройте PowerShell / Терминал в папке, в которой лежит **корневой файл `package.json`** (не в `apps/client` или `apps/server`).
4. Проверьте установку: `node -v` и `npm -v`.
5. Установите зависимости: `npm install`.
6. Соберите клиент и сервер: `npm run build`.
7. Запустите сервер: `npm start`.
8. Откройте в браузере **http://localhost:3000**. Создайте комнату, выберите героя и пригласите друзей.

**Windows PowerShell:** если появляется сообщение о запрете `npm.ps1`, используйте `npm.cmd install`, `npm.cmd run build`, `npm.cmd start` вместо обычного `npm`. Менять политику исполнения PowerShell не требуется.

Важно: терминал с сервером должен оставаться открытым. Для остановки нажмите `Ctrl+C`. После остановки сервера текущие комнаты и партии теряются.

## 2. Как играть с другого компьютера

Если оба компьютера подключены к одному Wi-Fi, на компьютере-хосте выполните `ipconfig` (Windows) или посмотрите IPv4-адрес Wi-Fi в настройках сети macOS. Друг откроет `http://IP_ХОСТА:3000`.

Пример адреса — `http://192.168.1.105:3000`; в вашем случае цифры будут другими.

Через Radmin VPN или другую VPN принцип такой же: используйте IP хоста в VPN. Нужно, чтобы компьютеры могли напрямую обмениваться трафиком; подключение к одному VPN-серверу само по себе не всегда гарантирует это. Если адрес не открывается, проверьте, что сервер запущен, оба устройства видят друг друга и входящие TCP-соединения на порт 3000 разрешены брандмауэром. Используйте обычную домашнюю Wi-Fi-сеть без гостевой изоляции клиентов.

**Устанавливать Node.js друзьям не требуется** — только на компьютере, который запускает сервер.

## 3. Как установить обновление

**Вариант A — Git:**

1. Остановите сервер `Ctrl+C`.
2. Сохраните свои незакоммиченные изменения, если правили исходники.
3. В корне репозитория выполните:

   ```bash
   git pull
   npm install
   npm run build
   npm start
   ```

4. В браузере сделайте жёсткое обновление: `Ctrl+F5` (Windows) или `Cmd+Shift+R` (Mac).
5. Создайте новую комнату.

**Вариант B — ZIP:**

1. Остановите сервер.
2. Сохраните прежнюю папку на случай отката.
3. Скачайте свежий ZIP с GitHub и распакуйте **в новую папку**.
4. Выполните `npm install`, `npm run build`, `npm start` в новой папке.
5. Обновите страницу и создайте новую комнату.

Не распаковывайте новую версию поверх старой вслепую: в старой папке могут оставаться устаревшие файлы.

## 4. Что посмотреть после обновления

- Создайте комнату хотя бы с двумя игроками и выберите одинаковый класс героя.
- Проверьте бросок кубиков, выбор и отмену грани до применения эффекта.
- Посмотрите журнал: новое событие появляется первым сверху.
- Проверьте короткие подсветки боевых действий и паузу перед атакой монстра.
- Попробуйте нажать «Покинуть игру» во время победы и после нулевого таймера — подтверждение должно быть поверх остальных окон, фон полностью затемнён.
- Проверьте переход на следующий этаж: старых монстров не должно быть.
- На маленьком ноутбуке и широком мониторе проверьте читаемость ролей и характеристик героев.

Остальные случаи перечислены в [STAGE_3_2_HOTFIX.md](STAGE_3_2_HOTFIX.md).

## 5. Ограничения и устранение неполадок

- **Не запускается `npm`:** убедитесь, что Node.js установлен; на Windows попробуйте `npm.cmd`.
- **Адрес недоступен у друга:** используйте локальный/VPN IPv4 хоста, проверьте порт 3000, брандмауэр и доступность сети.
- **Видите старое оформление:** остановите сервер, повторите `npm run build` и обновите браузер с очисткой кеша.
- **Сложные эффекты, артефакты, роли:** пока находятся в разработке; отсутствие полного эффекта не означает ошибку текущего этапа.
- **Партия исчезла после перезапуска:** сохранение партий в этом MVP не предусмотрено.

В демонстрационной версии ход длится 60 секунд. Для тестирования согласованных 15/5 секунд используйте переменные `TURN_SECONDS` и `SHORT_TURN_SECONDS`, описанные в корневом README.
