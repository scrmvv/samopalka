# Самопалка — 3.3.2: исправление исчезновения погибших монстров

## Проблема

После убийства второго монстра ранее убитый противник мог оставаться на поле полупрозрачной фигуркой и перекрывать живого монстра. Его нельзя было атаковать, поскольку сервер уже считал его погибшим. На поле также влияли мёртвые фигурки при перерасчёте кольца призванных монстров.

## Изменения

- В боевом интерфейсе показываются только **живые** монстры.
- Побеждённый босс исчезает с поля; состояние победы и журнал остаются прежними.
- Раскладка дополнительных монстров учитывает только живых противников.
- Тип спрайта оставшегося монстра не изменяется после смерти соседа.
- У невидимых/погибших интерактивных элементов отключён перехват нажатий (CSS-защита).
- Сервер сохраняет сведения о погибших противниках для истории боя, но не предлагает их в списке целей.

Это исправление не изменяет боевую механику, генерацию монстров, таймеры, отладочную панель и сетевую синхронизацию.

## Установка поверх 3.3.1

1. Остановить игровой сервер.
2. Распаковать `samopalka_stage3_3_2_dead_monster_patch.zip` в **корень** проекта с заменой файлов. Не нужно копировать файлы по одному.
3. В корневой папке проекта выполнить:

```powershell
npm.cmd run build
npm.cmd test
npm.cmd start
```

4. Обновить страницы у всех игроков (`Ctrl + F5` или `Cmd + Shift + R`).
5. Создать новую комнату и проверить на втором этаже или другом уровне, где можно победить несколько противников подряд.

## Контрольная проверка

- Монстр исчезает после смерти и больше не появляется в дальнейшем бою.
- Умерший монстр не перекрывает живого при выборе цели.
- После смерти первого монстра второй остаётся доступным, если подходит по правилам дальности.
- После смерти босса центр арены освобождается, а оставшиеся монстры сохраняются до победы над ними.
- Ход, атака и синхронизация в двух браузерах продолжают работать.

Автоматические тесты покрывают удаление мёртвых монстров из экранного списка и отсутствие их возрождения в серверном состоянии после убийства другого противника.
