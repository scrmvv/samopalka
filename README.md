# Самопалка

Браузерная многопользовательская настольная игра «Самопалка». В этом репозитории — **первый этап**: главное меню, создание комнат, подключение игроков и выбор героев.

## Что работает

- Создание комнаты на 2–6 игроков и вход по коду или ссылке.
- Выбор одного из шести героев без повторений в пределах комнаты.
- Статусы готовности участников и запуск комнаты хостом.
- Настройка названия комнаты и количества мест хостом.
- Синхронизация лобби в реальном времени через Socket.IO.
- Возврат в комнату после краткого обрыва соединения (до 60 секунд).
- Пиксельный интерфейс, рассчитанный прежде всего на браузер компьютера.

**Граница этапа:** после запуска комнаты отображается подтверждение «Отряд собран». Игровое поле, броски кубиков, таймеры, бои и артефакты в этой версии отсутствуют. Они будут разработаны отдельно.

## Требования

- Node.js 20.19+ (подойдёт актуальная версия LTS).
- npm (устанавливается вместе с Node.js).

## Установка и запуск

В корне репозитория выполните:

```bash
npm install
npm run build
npm start
```

Откройте **http://localhost:3000**.

Для разработки с автоматическим обновлением запустите две команды **в разных терминалах**:

```bash
npm run dev:server
npm run dev:client
```

В режиме разработки интерфейс доступен по **http://localhost:5173**, сервер работает на порту `3000`.

Проверить серверные тесты:

```bash
npm test
```

## Игра по сети

Сервер слушает `0.0.0.0:3000`. Участники могут подключаться по адресу `http://IP_компьютера:3000`, если находятся в одной локальной или виртуальной сети и имеют доступ к этому порту. Подойдут Radmin VPN и другие решения с маршрутизацией между участниками.

В лобби доступна ссылка-приглашение. При необходимости адрес компьютера, на котором запущен сервер, можно указать в «Настроить приглашение». Для подключений с другого ПК может потребоваться разрешить входящий TCP-порт `3000` в брандмауэре Windows.

## Структура

```text
apps/client/       React, TypeScript, пиксельный интерфейс
apps/server/       Node.js, Express, Socket.IO, комнаты
packages/shared/   Общие типы и описание героев
```

Данные комнат сейчас хранятся в памяти сервера: после его остановки комнаты исчезают. Регистрация и база данных на первом этапе не требуются.
