# Самопалка — публикация 3.4.2-test в GitHub

## Что это

Исходники последней закрытой тестовой сборки **3.4.2-test** (15.11.2026): React/Vite-клиент, Node.js/Socket.IO-сервер, общий модуль, серверные тесты и Game Simulator. Это тот же игровой исходный код, что находится в клиентской полной сборке 3.4.2; в этой версии дополнительно включены файлы симулятора.

Архив не содержит `node_modules`, скомпилированных `dist`, локальных `.env` и секретов. Его можно распаковать в корень репозитория с заменой совпадающих файлов. Сохраните собственные несохранённые правки до обновления.

## Если GitHub-репозиторий уже клонирован

На компьютере с рабочей копией репозитория:

1. Сделайте резервную копию или отдельный коммит незаконченных изменений.
2. Распакуйте `samopalka_3_4_2_GitHub_UPDATE.zip` **в корень репозитория**, с заменой файлов. Если предыдущая версия не 3.4.1, используйте полный архив.
3. Выполните в терминале (Windows PowerShell, из корня репозитория):

```powershell
npm.cmd install
npm.cmd run build
npm.cmd test
npm.cmd run simulate -- --games 100 --players 4 --seed 42

git status
git add -A
git commit -m "release: stage 3.4.2-test"
git push
```

Если локальная папка проекта **не** является клоном нужного репозитория (`git status` говорит `not a git repository`), сначала сделайте `git clone` и копируйте файлы в этот клон. Не запускайте `git init` поверх существующего репозитория.

## Если требуется чистый исходный проект

Распакуйте полный ZIP в отдельную папку, выполните `npm install`, `npm run build`, `npm test`. Потом переносите файлы в нужный Git-репозиторий, не копируя `node_modules` и `dist`. При удалении устаревших файлов обязательно проверяйте `git status` перед коммитом.

## Релиз

Рекомендуемый тег: `v3.4.2-test`. Описание изменений — `CHANGELOG.md` и `docs/STAGE_3_4_2.md`.

## Важно про тестовую панель

В закрытой тестовой версии `DEBUG_TOOLS` **включена по умолчанию** и доступна хосту комнаты. Для открытого публичного сервера отключайте её переменной `DEBUG_TOOLS=0` и перезапускайте Node.js. Если GitHub-репозиторий публичный, любой сможет увидеть исходники и способ включения панели — это ожидаемо для тестового проекта.

Новая параллельная выдача трёх артефактов по классам, весь каталог из таблицы 4.0, роли 3.5, админка. Действует тестовая схема наград из четырёх предложений с личными бросками на привале.

Архив проверен на целостность и наличие импортируемых локальных модулей. Полная сборка и npm-тесты **не запускались заново при упаковке** — перед публикацией выполните команды проверки из этого файла.
