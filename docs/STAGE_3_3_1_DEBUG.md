# Самопалка — 3.3.1: тестовая панель и исправление окна выхода

## Режим закрытого тестирования 3.3.3 (29.10.2026)

**В этой сборке панель включена по умолчанию.** Достаточно собрать и запустить:

```powershell
npm.cmd install
npm.cmd run build
npm.cmd start
```

После входа в комнату и начала партии у хоста появится кнопка **«ТЕСТ»** рядом с таймером. Обычные участники не видят панель и не могут выполнить команды напрямую: сервер отклоняет их из-за отсутствия прав хоста.

**Безопасность:** это версия только для закрытых комнат с доверенными участниками и не для открытого интернета. Хост комнаты может изменять состояние своего боя. Перед публичным размещением выключайте панель явной переменной `DEBUG_TOOLS=0` и перезапускайте сервер:

**CMD:**
```cmd
set DEBUG_TOOLS=0
npm.cmd start
```

**PowerShell:**
```powershell
$env:DEBUG_TOOLS = '0'
npm.cmd start
```

**Linux / macOS:** `DEBUG_TOOLS=0 npm start`. Значение `DEBUG_TOOLS=1` оставляет панель включённой. Если переменная не задана, панель включена.

## Возможности панели

1. **Грани кубика.** Выберите героя, сторону 1–6, реализованное игровое слово и число. Доступны: Удар, Щит, Лечение, Мана, Пусто, СамоУворот, Самощит + Насмешка. Грань активного героя можно изменять до броска, чтобы не изменять уже начатое действие.
2. **Характеристики.** Изменение HP, максимального HP, щита, маны и её максимума у живых персонажей. Смерть и победу тестируйте обычными игровыми действиями — HP нельзя вручную установить в 0.
3. **Эффекты.** Наложение и снятие существующих состояний: яд, слабость, оглушение, сон, паралич, уворот, регенерация, гниение.
4. **Противники.** Замена конкретного монстра или босса на карточку из каталога. Можно брать врагов с других этажей — это тестовый режим, а не правило обычной игры. Заменённому врагу восстанавливается полное здоровье.
5. **Контроль броска.** Задать два результата от 1 до 6 до обычного броска, затем нажать на одну из двух граней справа.
6. **Таймер.** Продлить текущий ход на 120 секунд.

Все изменения временные, применяются к **текущей партии в памяти сервера** и сбрасываются при создании новой партии, перезапуске сервера либо восстановлении соответствующих сущностей на следующем этаже. Это не постоянная админка и не редактор всех правил.

### Ограничение на новые слова

Через панель можно использовать только слова и состояния, обработчики которых есть в текущем движке. Добавление совершенно нового слова («Телепортация» и т. п.) без программирования его поведения не поддерживается. Настраиваемые составные грани и артефакты — дальнейшая разработка.

## Исправление окна выхода

У диалога «Покинуть отряд?» больше не появляются горизонтальная и вертикальная прокрутка при наведении. Затемнение страницы и положение диалога поверх окна победы сохранены.

## Быстрая проверка

- Обычный запуск без `DEBUG_TOOLS`: кнопка «ТЕСТ» есть только у хоста; у гостя её нет.
- Запуск с `DEBUG_TOOLS=0`: кнопки «ТЕСТ» нет, все команды `debug:*` отклоняются.
- Установите герою грань «Удар 7» и задайте принудительный бросок этой грани. В бою должен примениться именно урон 7 с учётом защиты.
- Наложите «Яд 2» — статус должен отобразиться у персонажа, затем сработать по правилам движка.
- Замените своего монстра на «Крысу», пройдите его ход, проверьте яд.
- Откройте подтверждение выхода, наведите на обе кнопки: внутренние скроллбары не появляются.

При ошибке сборки пришлите **первую строку ошибки TypeScript**, а не только последние строки npm.
