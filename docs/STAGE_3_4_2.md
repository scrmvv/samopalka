# Самопалка 3.4.2-test — доработки артефактов и привала

Небольшое обновление поверх **3.4.1**. Это не новая схема наград из трёх артефактов по выбранным классам: её заказчик согласовывает **отдельно**. Текущая последовательная система из четырёх вариантов сохранена, пока новая спецификация не реализована.

## Вошло в обновление

- **№4 — личный бросок на привале.** После победы каждый игрок видит кнопку «Бросить d6 и восстановить здоровье». Сервер принимает ровно один бросок от соответствующего участника, затем начисляет `min(макс.HP, текущее HP + 2 + d6)`. Погибшие в бою герои оживают на собственном броске. Пока все не бросили, награды недоступны. Результат каждого показывается всем участникам и в журнале.
- **№11 — выбор грани отдельным шагом.** Сначала выбирается артефакт, затем, только если требуется менять/усиливать грань, открывается экран с шестью гранями и кнопкой подтверждения. Никакая грань не предвыбрана. Артефакты без замены стороны применяются сразу. Для альтернативы `+1 к грани` используется тот же второй шаг.
- **№18 — таймер наград 60 секунд** на каждого игрока в существующей последовательной системе. Сервер следит за временем; если оно истекло, автоматически выдается безопасная альтернатива **+2 к максимальному HP**, без случайной замены стороны. После перехода очереди отсчёт запускается заново. На личные броски привала таймер выбора награды не распространяется.
- **№25 — начальный порядок граней.** Все стартовые эффекты героев сохранены, а пустые стороны перемещены в конец кубика. У героев с двумя пустыми гранями они стоят на 5–6; у героев с одной пустой гранью — на 6. Изменения влияют на номера физических сторон и на отображение результата броска.
- **№16 — монстры.** Сверены 34 типа противников на 1–6 этажах с листом «Монстры» в `Самопалка 4.0.xlsx`. Заданные в таблице HP, уровень, тип и **заполненные количества** совпадают с исходниками; правок каталога не потребовалось. В ячейке количества для босса «Прокаженный» значение в таблице пустое; в коде установлен один экземпляр как для остальных боссов.

## Быстрый ручной тест

1. Запустить партию на двух или трёх игроков, зачистить первый этаж через панель «ТЕСТ».
2. На привале проверить, что HP **не восстанавливается автоматически**, каждый игрок бросает d6 самостоятельно и видит прибавку `2 + результат` с ограничением максимума. Повторно бросить нельзя.
3. До броска последнего игрока убедиться, что экран получения артефактов не открылся. После всех бросков появляется прежняя раздача из четырёх предложений.
4. Выбрать артефакт, заменяющий грань: сначала нажать «Выбрать → грань», затем выбрать **сторону 2** на следующем экране и подтвердить. Проверить, что сторона 1 не изменилась.
5. Выбрать пассивный предмет без замены грани: второй экран для него не должен открываться.
6. На следующем привале не нажимать получение награды в течение 60 секунд. Проверьте, что сервер присвоит игроку +2 макс.HP и передаст выбор следующему участнику.
7. Проверить номер **1** как активную полезную грань, а **5 и 6** как пустые для героя с двумя пустыми гранями.

## Замечания по тестированию

- Привал и выдача наград работают на сервере и синхронизируются через Socket.IO. Разрешение на бросок проверяется по подключённому пользователю, не по присланному ID.
- Сессии комнат не сохраняются на диск при остановке сервера — поведение прежнее.
- После изменения стартовых граней старые автотесты сохраняют прежнюю *тестовую* карту для своих сценариев. Новый порядок проверяется отдельным тестом; в самой игре используются только новые карты.
- Отладочная панель включена **только для закрытой беты** и доступна хосту. Отключение: `DEBUG_TOOLS=0`.
- **Пока не входит:** новый параллельный выбор трёх артефактов по пяти классам, роли, новое лобби и админ-панель.

## Результаты разработки

- 223 из 223 серверных тестов (включая восемь новых сценариев 3.4.2) — успешно.
- 300 обычных симуляций и 100 ускоренных кампаний на шесть этажей — без найденных ошибок состояния.
- Проверены синтаксис TypeScript/TSX и отдельная строгая проверка типов серверного игрового ядра и симулятора.
- Полную клиентскую npm-сборку с Vite/React выполнить в локальной среде не удалось: недоступна часть npm-зависимостей. Перед отправкой клиенту выполнить `npm.cmd install`, `npm.cmd run build`, `npm.cmd test`, `npm.cmd start` и короткую браузерную проверку.
