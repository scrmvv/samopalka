# Самопалка — исправления по отзывам заказчика от 22.11.2026

**База патча:** GitHub-сборка **3.4.3-test** (до заклинаний). Версия этого патча: **3.4.3-feedback-test**. В изменения не включена отдельная ветка 3.4.4 со заклинаниями. Перенос на 3.4.4 потребует слияния/отдельного тестирования.

## Внесённые изменения

| № | Изменение |
|---|---|
| 1 | Составные грани `Удар/Лечение/Щит + Мана` дают ману владельцу грани независимо от цели. |
| 2 | `Разброс` теперь требует выбора соседних существ после выбора основной цели (до двух, если доступны; без соседей действует только на основную). Клиент показывает кандидатов; сервер валидирует выбор. |
| 3 | Вместо подписи `Сила` под Проклятым показана компактная текущая сила грани `⚔ N`. |
| 4 | `Очищение` тратит силу на снижение негативных эффектов по выбору игрока. На каждый эффект можно распределить 0..текущей силы; суммарно ровно столько, сколько допустимо. |
| 5 | В событиях атаки, лечения, статуса, гибели и выбора цели босса к названию героя добавляется никнейм. |
| 6 | Длинные имена монстров, включая Крысиного короля, переносятся внутри карточки. |
| 7 | Вопрос о графике — не программная правка; рекомендации по PNG/WebP и спрайтшитам Piskel обсуждены отдельно. |
| 8 | Хост может исключить другого игрока из лобби. Исключение во время боя и исключение самого хоста запрещены на сервере. |
| 9 | Реликвия с **полными** единицами HP увеличивает и максимум, и текущее HP; с **пустыми** — только максимум. |
| 10 | У бинарных статусов (Сон, Оглушение, Паралич, Окаменение) больше нет числа на бейдже; их серверное накопление нормализовано к присутствию/отсутствию. `Боль` и `Перезарядка` — слова/действия, не отдельные накапливаемые статусы. |
| 11 | После исключения за два пропущенных хода клиент очищает старую комнату и восстанавливает сетевое подключение без ручного обновления страницы. |
| 12 | Монстры с признаком `Позади:` располагаются вторым рядом позади передних монстров; добавлен визуальный маркер. |
| 13 | Значение стороны отображается фактическим: например, `Удар 1 (-1)` вместо `Удар 2 (-1)`. |
| 14 | При окаменевших гранях рядом с героем появляется бейдж `Окаменение`, приоритетный среди эффектов. |
| 15 | Увеличен предел силы эффектов через панель ТЕСТ: 1..500. |
| 16 | Окаменение не снимается очищением и удаляется после смерти героя. |
| 17 | `Прочность` уже не ограничивала урон Ядом. Правило сохранено и покрыто отдельным тестом. |
| 18 | У Вампира `Пиявка` усиливает всю сторону, в том числе `СамоЛечение`. |

**Специально не меняли:** нестандартное окаменение Горгоны и интерактивную логику `Бесплотности` Призрака — заказчик просил сохранить их.

## Что проверить вручную

1. Создать комнату с двумя игроками; у хоста появилась кнопка исключения другого участника, у гостя её нет. После исключения гость попадает на доступный главный экран.
2. Выдать через `ТЕСТ` реликвию `Реликвия · Здоровье` и проверить прирост как максимума, так и текущего HP; отдельно сравнить с `Реликвия · Запас HP`.
3. Проверить `Удар, Мана` на противнике и `Лечение, Мана` на союзнике: ману должен получить только владелец кубика.
4. Для `Разброса` выбрать основную цель и соседей; выбор должен требоваться в отдельном окне, когда соседи есть.
5. Для `Очищения` наложить на героя `Яд 2` и `Слабость 1`, применить `Очищение 2` и выбрать, какую силу убрать. Окаменение должно остаться.
6. Показать Рыцарю негативный эффект граней `Слабость 1` и проверить итоговую запись вида `Удар 1 (-1)`.
7. Понаблюдать за длинным именем `Крысиный король`, монстрами `Позади` и статусом `Окаменение` при разных размерах экрана.
8. На двух последовательных простоях игрока убедиться, что приложение возвращает его к действующему главному экрану без обновления.
9. Сверить игровой журнал: действия по героям должны содержать их никнеймы.

Для составных граней, отсутствующих в ограниченном тестовом каталоге артефактов 3.4.3, ручное воспроизведение потребует добавления таких граней в набор тестовых данных либо отдельного тестового сценария. **Автоматические тесты уже покрывают эти комбинации непосредственно в движке**.
