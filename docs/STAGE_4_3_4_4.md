# Самопалка — этап 4.3–4.4: завершение редакторов баланса

База второй части: этап 4.1–4.2 с ENV-патчем. Общий патч этапа 4 рассчитан на `samopalka_3.4.4_RUNTIME_FIXED_FULL.zip`. Это не замена полного исходного каталога и не исправление всех замечаний третьего этапа.

## Возможности

- `/admin`: шесть вкладок. Герои, монстры, боссы (первая часть), артефакты, заклинания, эффекты (вторая). Поиск по названию, ID и описанию, фильтры категории/этажа, сброс карточки и общее сохранение.
- 157 карточек артефактов: 97 обычных (замена грани, HP, расходуемое лечение, бонус или множитель грани), 54 заклинательных и 6 связанных пассивных. 101 карточка имеет собственный редактируемый числовой параметр: 97 обычных и 4 пассивных. Два бесплатных каста сохраняют фиксированные условия. Для 54 заклинательных карточек откройте «Заклинания» и найдите ID карточки; две карты имеют по два действия.
- 59 действий заклинаний: 3 врождённых и 56 артефактных. Цена маны, числовая сила каждого поддерживаемого компонента, скидка при повторе и мана за уничтожение цели там, где такое правило уже предусмотрено. Бинарные слова без числовой силы и условия применения не редактируются. Обычная стоимость минимум 1, реактивный/бесплатный каст остаётся бесплатным по прежним правилам.
- 6 общих эффектов: урон за единицу Яда, лечение за единицу Регенерации, снижение за единицу Слабости, шаг Роста и Гниения на гранях героев, множитель Боли от Паралича. Исходные значения — 1. Для Роста и Гниения монстров сохраняются отдельные параметры карточки монстра. Окаменение, Сон, Оглушение и другие фиксированные условия не превращены в произвольные числа.
- Все изменения используются в расчётах новых партий. Обычные награды и выдача через ТЕСТ получают значения из снимка партии. Описания изменённых карт содержат актуальные значения и отдельно обозначенную исходную карту. Сервер не доверяет числам, присланным игровым клиентом.
- Схема `balance.json` расширена тремя разделами (`artifacts`, `spells`, `effects`). При старте прежняя точная схема загружается с исходными значениями новых разделов, сохраняются прежние герои, противники и ревизия. При первом сохранении записывается новая схема, прежний файл становится `.bak`. Частично повреждённые файлы не заменяются молча. Уже начатая партия хранит свою копию всех параметров.

## Установка

Остановите сервер. Сделайте копию рабочего каталога `data/` (или отдельного `BALANCE_FILE`) и `.env`. Не удаляйте их.

На macOS из корня существующего проекта 4.1–4.2 + ENV:

```bash
unzip -o ~/Downloads/samopalka_4.3-4.4_PATCH.zip
npm run build
npm test
npm start
```

Общий патч этапа 4 распаковывается в корень **3.4.4 Runtime Fixed**. Если ветка GitHub содержит более старую версию, используйте полный архив или предварительно перенесите 3.4.4, затем проверьте `git status` и diff. Не заменяйте локальные настройки. При отсутствии `.env` выполните `[ -f .env ] || cp .env.example .env`, затем `nano .env`. На Windows: `if (-not (Test-Path .env)) { Copy-Item .env.example .env }`. Реальный `.env` не входит в архив. Для локального запуска установите `HOST=127.0.0.1`, `ADMIN_ALLOW_HTTP=1`, `ADMIN_PASSWORD` не короче 12 символов. Для публичного HTTPS-сервера `ADMIN_ALLOW_HTTP=0`, `DEBUG_TOOLS=0`. Адрес локальной админки: `http://localhost:3000/admin`.

## Ручная приёмка

1. Убедитесь, что ранее изменённое HP героя сохранилось после обновления. Проверьте все шесть вкладок и поиск.
2. В «Артефакты» найдите `art-013`, измените силу грани с 2 на 5. Сохраните. В новой партии выдайте через ТЕСТ эту карточку и выберите грань; она должна стать Ударом 5. В обычном выборе награды эта карточка также имеет обновлённую силу, если выпадет.
3. В «Заклинания» найдите `hero-adept-shield2`, задайте стоимость 4, силу щита 7. В новой партии выберите Мага, выдайте 5 маны через ТЕСТ, примените щит к себе: останется 1 мана, щит увеличится на 7. При 3 маны обычный каст недоступен. Для артефактного заклинания можно аналогично изменить и выдать `spellcard-009`.
4. В «Эффекты» задайте урон за единицу Яда 2. В новой партии наложите через ТЕСТ Яд 2; при завершении хода потеря HP составит 4 (щит не поглощает Яд). Проверьте, что старые партии не получают новых значений при сохранении.
5. Перезапустите сервер; войдите снова и убедитесь, что баланс сохранился. Сбросьте тестовые карточки до исходных значений, нажмите «Сохранить». Проверьте второй клиент.

## Границы задачи

В этапе 4 не добавлены новые игровые сущности или правила, не редактируются отсутствующие обработчики и нет произвольного конструктора эффектов. По прежнему плану 3.4.4 заклинательные и связанные пассивные карты доступны через ТЕСТ, а обычная колода наград содержит 97 поддерживаемых обычных карт; их включение в обычный драфт не входит в этот патч. Нерешённые замечания заказчика (включая перенос Крысиного короля, отдельные логи и ручное очищение заклинаниями) не объявляются закрытыми. Наличие описанного правила в старой карточке не означает, что любая комбинация реализована без ошибок.
